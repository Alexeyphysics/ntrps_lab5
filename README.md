## 📌 Описание программного комплекса

Комплексное десктопное приложение на базе фреймворка **PySide6 (Qt6)**, объединяющее полный жизненный цикл работы с текстовыми данными:
1. **Web-Scraping (ЛР1):** сбор отзывов по объекту «Сбербанк» с контролем пауз и исключением дубликатов.
2. **Data Engineering (ЛР2):** структурирование датасета, генерация аннотаций CSV (pandas), реорганизация каталогов (префиксы классов, случайная нумерация 0..10000 без коллизий).
3. **Desktop GUI & Iterators (ЛР3):** оконный интерфейс с пошаговой навигацией по отзывам через протокол итератора.
4. **EDA & NLP Analysis (ЛР4):** расчет статистик длин текстов, построение распределений Boxplot, лемматизация (pymorphy3) и построение частотных гистограмм ключевых слов.
5. **Quality Assurance & Deployment (ЛР5):** комплект из 10 автотестов (pytest) с покрытием до 96%, контейнеризация (Docker) и сценарии автозапуска.

📖 Руководство пользователя (User Mini-Guide)
Интерфейс приложения разделен на 3 логические вкладки:
Вкладка 1: «Датасет и Скрейпинг»
Выбор каталога: кнопка «Выбрать папку...» позволяет указать путь к любой директории датасета через системный диалог QFileDialog.
Запустить Web-Scraping: кнопка запускает фоновый сбор отзывов с сервиса «Отзовик».
Создать аннотацию: сохраняет CSV-таблицу путей и классов (annotation.csv).
Создать копии: реорганизует файлы в плоские каталоги (<класс>_<номер>.txt или случайные 0..10000.txt).
Вкладка 2: «Просмотр отзывов»
Панель кнопок ★ 1 ... ★ 5 последовательно извлекает отзывы выбранной оценки с помощью итератора ReviewIterator.
В окне отображаются метаданные отзыва, заголовок и полный текст.
По окончании списка выводится уведомление QMessageBox, и указатель итератора сбрасывается в начало.
Вкладка 3: «Анализ и Графики (EDA)»
Рассчитать статистику: выводит в текстовое поле отчет описательной статистики (describe) и метрики по каждому классу.
Построить Boxplot: генерирует и отображает внутри окна график распределения длины отзывов.
Частотный анализ (NLP): выполняет лемматизацию текстов и строит горизонтальную гистограмму топ-15 слов для негативных (★ 1) или позитивных (★ 5) отзывов.
