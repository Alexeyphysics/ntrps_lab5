## 📌 Описание программного комплекса
Комплексное десктопное приложение на базе **PySide6 (Qt6)**, объединяющее полный жизненный цикл работы с данными:
1. **Web-Scraping (ЛР1):** автоматизированный сбор отзывов с сервиса «Отзовик» с рандомизацией пауз и защитой от дублирования.
2. **Data Engineering (ЛР2):** структурирование датасета, генерация аннотаций в формате CSV (`pandas`), реорганизация каталогов (префиксы классов, случайная нумерация без коллизий).
3. **Desktop GUI & Iterators (ЛР3):** оконный интерфейс со стилем Fusion и пошаговым просмотром отзывов через стандартный протокол итератора.
4. **EDA & NLP Analysis (ЛР4):** расчет статистик длины текстов (`describe`), построение распределения `Boxplot`, удаление стоп-слов (`nltk`) и лемматизация (`pymorphy3`) с визуализацией частотности слов.
5. **Quality Assurance & Deployment (ЛР5):** набор автотестов (`pytest`), контейнеризация (`Docker`), сценарии автозапуска (`run.bat`, `run.sh`).

📖 Руководство пользователя (User Mini-Guide)
Интерфейс разделен на 3 вкладки:
Вкладка 1: «Датасет и Скрейпинг»
Выбор каталога: поле вверху окна позволяет выбрать любую папку датасета через диалог QFileDialog.
Запуск скрейпинга: кнопка обращается к сервису «Отзовик» и докачивает отзывы.
Создать аннотацию: сохраняет CSV-таблицу путей и классов.
Создать копии: реорганизует файлы в плоские каталоги (<класс>_<номер>.txt или случайные 0..10000.txt).
Вкладка 2: «Просмотр отзывов»
Панель кнопок ★ 1 ... ★ 5 последовательно выводит отзывы выбранной оценки через итератор.
По окончании списка выводится уведомление QMessageBox, и итератор сбрасывается в начало.
Вкладка 3: «Анализ и Графики»
Рассчитать статистику: выводит сводную таблицу describe и метрики по классам.
Построить Boxplot: отображает график распределения длин отзывов.
Частотный анализ (NLP): лемматизирует отзывы и строит график топ-15 слов для негативных (★ 1) или позитивных (★ 5) отзывов.
🚀 Инструкции по развертыванию (Deployment)
Способ 1. Локальный запуск на Windows (в 1 клик)
Просто запустите файл run.bat двойным щелчком мыши. Скрипт сам создаст виртуальное окружение venv, установит библиотеки из requirements.txt и запустит GUI.
